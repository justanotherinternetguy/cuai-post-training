# Teacher LLM tests: summary and results

Status as of 2026-11-06 (Unicorn cluster, user `qx235`). Project question: does a base model fine-tuned on a post-trained teacher's outputs inherit the teacher's preferences (mode collapse)?

**Short version:** all five teachers are downloaded, load in vLLM on 2x A6000, and have a complete preference eval (sampling + exact token-tree walk, re-run on 2026-11-06). The toolchain smoke test passes. Every teacher shows strong mode collapse on "pick one" questions (7, 42, blue, heads, apple, Japan/Paris). Gemma-3-27B is the most collapsed and OLMo-2-32B the least. Full results: `teacher_prefs_results.md`. Qwen3.8-27B (outside the teacher set) passed a basic inference test; its weights were deleted on 2026-11-06 to free disk. The data generation and SFT code (`gen/`, `train/`) is not written yet, and no student model is chosen.

## 2. Preference eval (mode collapse) results

Full results, method and figures: **`teacher_prefs_results.md`** (generated by `analysis/make_report.py` from run 7g). Interactive view: the "Teacher answer distributions" dashboard (see README). Main findings:

1. **Shared top answers.** All five teachers give the same top answer on 5 of 10 questions: 7 (1-10), 42 (1-100), blue, apple, heads.
2. **Ranking, most to least collapsed** (mean tree-walk entropy, bits): Gemma-3-27B 1.46 < Qwen2.5-32B 1.69 < Qwen3-32B 2.13 < Mistral-3.1-24B 2.26 < OLMo-2-32B 3.56.
3. **Teacher-specific answers** on vacation country, city, animal, first name and letter (for example first name: Liam / Emma / John / Elara / Alex). These questions can show whether a student picks up its own teacher's preference.
4. **One wording is much more collapsed than all 10 pooled** (for example Gemma 0.38 vs 1.46 bits).
5. **Sampling and the tree walk agree:** same top answer in 50 of 50 teacher-question pairs, mean entropy gap 0.04 bits.

The round-3 tables that were here (candidate-list logprob mode, 27 colors) are superseded by the tree walk, which needs no candidate list.
